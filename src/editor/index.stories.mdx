# Editor

The components in this directory are centered on Alu's rich text editor, implemented in SlateJS.
Here you can find the buttons that a user can press when interacting with the editor, the `Leaf` and `Element`
functions that render rich text, and functions for rendering an interactive rich text editor (`RenderEditor`).

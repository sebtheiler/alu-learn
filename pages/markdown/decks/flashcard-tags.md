## Tags

Tags help you organize your flashcards into categories.  It is recommended to keep your flashcards in a small number of decks and use tags to sort them for studying.

### Creation
Tags should be separated by commas. For example:
`Calculus, Integrals, Exponentials`.  This makes tags case sensitive. `calculus` =/= `Calculus` - be careful when creating tags or it will be a pain to change them. Trailing and prefixing white space, however, is entirely irrelevant.

The field for creating tags is located below the "Back" side when creating or editing flashcards, and above the submit button.

As with the front and back sides of a card, the tags field can be [frozen](/help/freezing-fields/), making it easier to create multiple flashcards with similar or identical tags.

### Searching and Custom Study
You can search for flashcards based on their tags. To do this, go to [custom study](/flashcards/search/) and specify the tags you would like to search in under the field titled "List of tags to search in (separate with commas)".  This will return flashcards that have ALL of the specified tags.  We do not currently support more advanced logical queries (e.g., OR, NOT), but are looking to implement this functionality in the future.  As stated earlier, tags are case sensitive.

After searching for flashcards with some given tags, you can press the "Study these flashcards (Custom Study)" button to only study flashcards with the specified tags.  This can be useful when studying for a test on a specific topic or in a specific class.

### Reserved tags
As of now, `leech` is the only reserved tag.  Giving a card the `leech` tag will mark it as a leech. For further information see the [leech help page](/help/leeches/).

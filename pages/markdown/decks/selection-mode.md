## Selection Mode
Selection mode allows you to perform "bulk operations" on flashcards.  This means you can add new tags to multiple flashcards at once, or remove old tags from multiple flashcards at once.


You can edit selection mode when browsing flashcards in a deck by pressing "Selection Mode" at the top of the page.  Once in selection mode, there will be checkboxes on the top left of each flashcard.  When you check a checkbox, that flashcard is added to the list of selected flashcards.


After you select one or more flashcards, you will see new options at the top of the screen.  For example, the "Tag Editor" option allows you to perform operations with the tags of the selected flashcards, such as adding a new tag to all selected flashcards.  Selected flashcards that already have the tag you are adding will be ignored, and selected flashcards that do not have the tag you are trying to remove will not cause an error.

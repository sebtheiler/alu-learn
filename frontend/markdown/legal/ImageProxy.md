## What is Alu?

Hi there! You're probably here because Alu scraped an image from your website using its image proxy.

Alu is a free education site that aims at pushing education into the future. At the moment, Alu is focusing on creating the world's best spaced repetition flashcard system, so that students can spend less time memorizing and more time critically engaging with content.

## What's happening with my images?

Alu fetched one of the images on your website because a user wanted to include that image in a flashcard.

By doing this, that user has asserted that they have the right to use your image, and will take responsibility in regards to credit ([Terms of Service](/legal/tos/)). Because Alu doesn't want to cause any extra server-traffic for you than absloutely necessary, it caches all requests for the day.

If you are opposed to any of this, you can block Alu's user agent (see bottom) or Alu's IP address. If this is the case, we apologize for any trouble Alu may have caused.

If you believe an Alu user is violating applicable copyright law by using your images, please the [DMCA notice](/legal/dmca/)

# Alu Learn Storybook
Storybook is a tool that helps build UI components in isolation from Alu's business logic, data, and context.
This makes it easier to rapidly prototype and share different components.

On the left, there is a list of different UI components. You can view each component by clicking on it.
Some components have multiple "stories" for different states. For example, the `Button` component has
a `Primary` state, a `Block` state, and other states. Each state represents a specific use-case for that
component.

Some components have _controls_. These appear at the bottom of the page when you select a component.
You can freely modify the controls to see how they affect the component.
